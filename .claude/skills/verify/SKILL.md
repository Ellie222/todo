프로젝트 루트에서 아래 두 검사를 실행하고 결과를 보고하세요.

1. `npm run lint`
2. `npx tsc --noEmit`

첫 번째가 실패해도 두 개 모두 실행하세요. 실패가 있으면 파일, 줄 번호, 메시지를 알려주고, 내가 변경해서 생긴 오류는 고치세요. 이미 있던 관련 없는 오류는 건드리지 말고 언급만 하세요. 둘 다 통과할 때까지 다시 실행한 뒤, 무엇이 통과했고 무엇이 통과하지 못했는지 있는 그대로 말하세요.
